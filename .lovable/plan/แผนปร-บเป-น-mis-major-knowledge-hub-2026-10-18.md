# แผนปรับเป็น MIS Major Knowledge Hub

## (A) โครงสร้างเดิมที่พบ
- 3 หน้า: `/` (ค้นหา + ลิงก์เอกสาร `href="#"` 3 อัน + แถบกรองตามภาควิชา บัญชี/บริหารธุรกิจ/สถิติ), `/schedule` (ตารางสัปดาห์ จ-ศ 08-18 น. + รายการวิชาให้กดเพิ่ม/ถอน), `/course/$code` (กลุ่มเรียน, กราฟเกรด A-F, รีวิวมีดาว)
- ข้อมูลทั้งหมดอยู่ใน `src/lib/courses.ts`: 7 วิชาตัวอย่าง (หลายสาขา) ที่ AI สร้างขึ้นเอง รวมอาจารย์ ห้อง เวลา เกรด รีวิว ซึ่งยังไม่ได้ติดป้ายว่าเป็นตัวอย่าง
- ตารางเรียนเก็บในหน่วยความจำ (หายเมื่อรีเฟรช) ไม่มีระบบตรวจเวลาชน ไม่มีข้อมูลวันสอบ
- แถบด้านบนใช้ชื่อ "REG-CBS" และชื่อ/รหัสนิสิตที่ตายตัว (PONGPIPAT P.)
- ไม่มี backend ไม่มีระบบล็อกอิน

## (B) แผนแก้ UX/UI แบบเป็นขั้นตอน
1. **ข้อมูล (`src/lib/courses.ts`)** — คงฟิลด์และฟังก์ชันเดิมไว้ทั้งหมด แต่เพิ่มฟิลด์แบบไม่บังคับ: `category` (GenEd / วิชาแกน / วิชาบังคับสาขา / วิชาเลือกสาขา / วิชาเลือกตามเงื่อนไข / วิชาเลือกเสรี), `term` (ต้น/ปลาย/ไม่ทราบ), `description`, `instructorShort`, `midtermExam`, `finalExam`, `maxSeats`, `isSample` (ข้อมูลตัวอย่างหรือไม่)
   - เพิ่มรายการรหัสวิชาตามหลักสูตรที่ให้มา (แกน 18 รหัส, บังคับสาขา 7 รหัส, เลือกสาขา 7 รหัส) โดยใส่เฉพาะรหัสและหมวด ชื่อ/หน่วยกิต/เวลาที่ไม่มีข้อมูลจะแสดงว่า "ยังไม่มีข้อมูล"
   - 7 วิชาเดิมไม่ลบ แต่ติด `isSample: true` และแสดงป้าย "ข้อมูลตัวอย่าง" ทุกจุดที่แสดงเวลา อาจารย์ ห้อง เกรด
   - วิชาที่ไม่อยู่ในรายการ MIS (เช่น 2603201, 2601201) ยังเก็บไว้ แต่ซ่อนจากหน้าค้นหาเริ่มต้น (ดูได้ผ่านตัวเลือก "แสดงวิชาตัวอย่างอื่น")
2. **ไฟล์ใหม่ `src/lib/curriculum.ts`** — โครงสร้างหน่วยกิต 138 / GenEd 33 / เฉพาะ 99 / แกน 51 / บังคับสาขา 21 / เลือกสาขา ≥12 / เลือกอื่น ≥15 / เสรี 6 พร้อมข้อความเงื่อนไขตามที่ให้มาคำต่อคำ
3. **แบรนด์และแถบด้านบน (`TopBar.tsx`, `__root.tsx`)** — เปลี่ยนชื่อเป็น "MIS Major Knowledge Hub" เพิ่มเมนู หน้าแรก / ค้นหารายวิชา / หลักสูตร / ตารางเรียน; บนมือถือเป็นเมนูแบบพับ; กล่องชื่อนิสิตเปลี่ยนเป็น "โหมดสาธิต (ยังไม่ได้เข้าสู่ระบบ)"
4. **หน้าแรก (`index.tsx`)** — ศูนย์รวมเป็นการ์ด: คู่มือการลงทะเบียน, คู่มือประจำภาค, ปฏิทินการศึกษา, ข่าวสาร/ประกาศ ถ้ายังไม่มีลิงก์จริงจะแสดง "ยังไม่มีเอกสาร — รอลิงก์ทางการ" (ไม่ใช่ `href="#"`) พร้อมทางลัดไปหน้าค้นหาและหน้าหลักสูตร
5. **หน้าค้นหาใหม่ `/courses` (`courses.tsx`)** — ย้ายระบบค้นหาเดิมมาไว้ที่นี่ ตัวกรองเปลี่ยนจากภาควิชาเป็นหมวดวิชา 6 แบบ + เทอม (แสดงเฉพาะเมื่อมีข้อมูล) ป้ายแต่ละหมวดมีสีของตัวเองและมีคำอธิบายสั้นเมื่อแตะ
6. **หน้าหลักสูตรใหม่ `/curriculum` (`curriculum.tsx`)** — แผนภาพสัดส่วนหน่วยกิต รายการรหัสวิชาแต่ละหมวด กล่องคำเตือน "ข้อมูลตามหลักสูตรที่ผู้ใช้ให้มา โปรดตรวจสอบกับประกาศทางการก่อนใช้จริง" และกล่อง "ประเด็นรอยืนยัน" (ดู D) ซึ่งจะไม่ตีความแทน
7. **หน้ารายละเอียดวิชา (`course.$code.tsx`)** — รหัส/ชื่อ, คำอธิบาย, หน่วยกิต, ป้ายหมวด, เทอม; การ์ดแต่ละเซค: อาจารย์ (ชื่อ/ชื่อย่อ), เวลาเรียน, สอบกลางภาค, สอบปลายภาค, จำนวนรับสูงสุด, ปุ่มเพิ่มลงตาราง ช่องที่ไม่มีข้อมูลจะขึ้น "ยังไม่มีข้อมูล" กราฟเกรดเดิมคงไว้แต่ติดป้ายว่าเป็นตัวอย่าง
8. **ความเห็นนิสิต (ในหน้าวิชา)** — เลิกแสดงดาวในหน้าจอ (ข้อมูลเดิมยังเก็บไว้) เปลี่ยนเป็นข้อความพร้อมเซคและอาจารย์; แบบฟอร์มส่งความเห็น (ข้อความ, เลือกเซค, ชื่ออาจารย์ — ไม่บังคับ) ที่แสดงผลเฉพาะในหน้าจอปัจจุบัน และมีป้าย "โหมดสาธิต: ความเห็นจะไม่ถูกบันทึกและจะหายเมื่อรีเฟรช"
9. **ตารางเรียน (`schedule.tsx`)** — คงตารางเดิม เพิ่มการตรวจเวลาเรียนชนกัน (ช่องที่ชนมีขอบสีแดงลายทาง + แถบเตือนบอกคู่วิชาที่ชน) ตรวจวันสอบกลางภาค/ปลายภาคชนกันเมื่อมีข้อมูล ถ้าไม่มีข้อมูลจะขึ้น "ตรวจวันสอบไม่ได้ — ยังไม่มีข้อมูล"; รายการวิชาด้านข้างกรองตามหมวด MIS แทนภาควิชา; มีแถบ "นี่เป็นแบบจำลอง ไม่ใช่การลงทะเบียนจริง"; บนมือถือแสดงเป็นรายการตามวันแทนตารางกว้าง
10. **Responsive + ชื่อหน้า** — ปรับทุกหน้าสำหรับมือถือ/เดสก์ท็อป และอัปเดตชื่อหน้า/คำอธิบายของทุกหน้าเป็นแบรนด์ใหม่

## (C) ทำได้ฝั่งหน้าเว็บ (mock) เทียบกับต้องใช้ backend
| ฟีเจอร์ | ทำแบบ mock ได้เลย | ต้องใช้ backend |
|---|---|---|
| ค้นหา ป้าย หลักสูตร หน้ารายละเอียด | ได้ทั้งหมด | ไม่จำเป็น |
| ตรวจเวลาเรียน/วันสอบชน | ได้ (คำนวณในเครื่อง) | ไม่จำเป็น |
| เก็บตารางเรียนข้ามรีเฟรช | เก็บในเบราว์เซอร์ได้ (เฉพาะเครื่องนั้น) | ถ้าต้องการใช้ข้ามอุปกรณ์ |
| ส่งความเห็นนิสิต | แสดงชั่วคราวเท่านั้น | ต้องมีฐานข้อมูล + การคัดกรองความเห็น |
| ล็อกอิน / โปรไฟล์ | ไม่ทำ | ต้องมีระบบบัญชีผู้ใช้ |
| ข่าวสาร/เอกสารที่แก้ไขได้ | ใส่ไว้ในโค้ด | ต้องมีหน้าผู้ดูแล |

**Prototype (รอบนี้):** ไม่เชื่อม backend ไม่ขอรหัสผ่าน/คีย์ใด ๆ ทั้งหมดเป็นโหมดสาธิตที่ติดป้ายชัด
**Production (ต้องอนุมัติก่อน):** เปิด Lovable Cloud เพื่อล็อกอิน (อาจจำกัดเฉพาะอีเมล @student.chula.ac.th), บันทึกตารางเรียน, เก็บความเห็นพร้อมระบบรายงาน/ผู้ดูแล, ระบบสิทธิ์ผู้ดูแลสำหรับแก้ข่าวและเอกสาร, และนโยบายความเป็นส่วนตัว

## (D) ความเสี่ยงและสิ่งที่ต้องให้ยืนยัน
1. ข้อความ "ถ้าลงเกิน 12 จะกลายเป็นวิชาเลือก" — หมายความว่าหน่วยกิตเลือกสาขาที่เกิน 12 นับเป็น "วิชาเลือกอื่น ≥15" ใช่หรือไม่? จะแสดงเป็น "รอยืนยัน" จนกว่าจะชัด
2. ผลรวม: 51+21+12+15 = 99 ตรงกับหมวดเฉพาะ และ 33+99+6 = 138 — ขอยืนยันว่า "≥15" รวมวิชาโทนอกคณะด้วยหรือไม่ และมีหน่วยกิตขั้นต่ำต่อกลุ่มหรือไม่
3. หน่วยกิตและชื่อวิชาของแต่ละรหัส (แกน/บังคับ/เลือกสาขา) และรายการวิชาภาษาอังกฤษของ GenEd — ข้อความเดิมจัดวางไม่ชัด ขอรายการชื่อ+หน่วยกิตที่แน่นอน
4. เทอมต้น/ปลายของแต่ละวิชา, เซค, อาจารย์, เวลาเรียน, วันสอบ, จำนวนรับ — ต้องมาจากแหล่งทางการ (เช่น ไฟล์ตารางสอน) ไม่เช่นนั้นจะขึ้น "ยังไม่มีข้อมูล"
5. ลิงก์เอกสารจริง (คู่มือ, ปฏิทิน) และข่าวประกาศ — ขอ URL หรือไฟล์
6. 7 วิชาตัวอย่างเดิม: เก็บไว้แต่ติดป้าย "ตัวอย่าง" (ค่าเริ่มต้นของแผน) หรือจะให้ซ่อนทั้งหมด?
7. ความเสี่ยง: ผู้ใช้อาจเข้าใจผิดว่าตารางเรียน/ความเห็นถูกบันทึกจริง — ป้องกันด้วยป้ายโหมดสาธิตทุกหน้า
8. URL เดิม `/`, `/schedule`, `/course/$code` คงไว้เหมือนเดิม; เพิ่มแค่ `/courses` และ `/curriculum`
